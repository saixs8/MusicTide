# USB 副屏实现计划

> 本文件为后续硬件规划，保留早期设计讨论。当前 v0.6.0 已实现 Windows 音乐终端、80 频段、实时歌词及音乐玩法；自定义 USB CDC 与设备固件尚未实现。当前软件说明以根目录 README 为准。

## 推荐低价方案

使用 ESP32-S3 开发板，优先选择带原生 USB 和 PSRAM 的版本，搭配 3.5-4.0 寸 SPI TFT。

常见物料：

- ESP32-S3 DevKit，带原生 USB，最好带 PSRAM
- 3.5 寸 ILI9488/ST7796 或 2.8 寸 ILI9341 SPI TFT
- 短 USB-C 数据线
- 如果屏幕模块不是 3.3 V 逻辑兼容，增加电平转换

PC 不建议传整帧 RGB 图像，而是传语义数据：

- 48-64 个频段 K 线：开盘、高点、低点、收盘、涨跌、形态
- 1 个全局音量/节拍值
- 歌词切换事件
- 粒子消散种子或事件参数

这样 USB 带宽很小，屏幕端也不会依赖 PC 端的逐像素刷新。

## 歌词来源策略

建议按优先级逐步做：

1. 手动粘贴歌词或读取 LRC 文件
2. 读取歌曲同目录或播放器缓存中的 LRC
3. 通过窗口标题/媒体会话获取当前歌曲信息
4. 针对酷狗等播放器做专用适配，需要先确认当前版本的缓存路径和可用接口

## 当前原型边界

当前 EXE 先验证视觉效果：

- 频率分布到 K 线柱的映射
- 每帧细微变化和周期换柱
- 红绿 K 线及多种 K 线形态
- 歌词底部显示和粒子消散切换

下一阶段是在保留现有音频和 K 线计算逻辑的基础上，增加 USB CDC 数据发送和屏幕端固件渲染。
