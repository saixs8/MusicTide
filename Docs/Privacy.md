# 数据、网络与隐私

## 本机读取和保存

程序捕获默认系统回放音频，读取支持的音乐播放器媒体会话及窗口文本；需要时对播放器的时间／歌词区域进行 OCR。播放控制会发送用户点击的切歌、暂停、停止及音量指令。

程序旁的 `Settings/` 保存参数，`Data/` 保存已听歌曲采样、歌词缓存、关键词学习结果及虚拟交易记录。安装版对应安装根目录下的 `App/Settings` 和 `App/Data`；手动发布版对应 `Output-Major` 下同名目录。

默认不保存原始音频录音。诊断工具可能输出窗口截图、歌词、进度、进程信息或本机路径；这些诊断资料不要直接当公共源码上传。

## 联网行为

| 功能 | 联网对象／发送内容 |
|---|---|
| 完整安装或联网补装 | Ollama 模型仓库，下载固定 manifest 对应的 blob；不发送歌词语料 |
| 首次在线歌词匹配 | 网易云歌词接口／LRCLIB；发送歌名、歌手和必要时长等匹配信息 |
| 本地 AI 分析 | 配置的本机 Ollama HTTP 地址；发送已听歌词片段供本机推理，拒绝远程地址和云端模型 |
| 源码还原与构建 | .NET 包源／Windows SDK 引用；开发环境需要相应包已缓存或联网 |

离线安装不下载模型。选择“联网补装”会打开安装器，由用户点击安装；未同意补装时不会后台自动下载模型。“不再询问”只关闭提醒，不删除待补装状态。

软件没有实现账户注册、埋点上报或远程听歌历史同步。其他程序自身的网络行为、已有 Ollama 服务的配置不由本软件控制。

## 管理数据

退出软件后备份整个 `Settings/` 与 `Data/` 即可保存配置和历史。若删除数据会丢失历史，请先自行备份。发布新版时保留这两个目录；源码包按白名单导出，不包含它们。
