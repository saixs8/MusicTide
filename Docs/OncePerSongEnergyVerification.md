# v0.8.3 连板次数与实时量能修复

## 连板

- 同一首歌最多触发一组；组内板数仍按已有设置随机选择。
- 高能量持续、进度跳转、设置修改及关闭再开启保留已经使用的次数。
- 天地板盲盒与普通高潮共享同一次机会，不能逐根重排队。
- 仅切歌重置次数；取消当前效果与新歌曲重置分别使用 Cancel / Reset。

## 量能

- 原量能共用行情的相对归一化数值，静音期间可能重复计算最后一个 FFT 窗口。
- 新量能独立使用实际 FFT 幅度，对数显示范围为 -72 至 -6 dB；40 毫秒上升、160 毫秒回落。
- 静音或 350 毫秒未收到音频包后清除目标幅度，平滑回落。量能区域位置不变。
- 现场原采集在 IAudioClient.Initialize 返回 0x88890004 后退出。改为释放接口、每秒重新选择默认设备，并校正 COM 方法的 PreserveSig 声明。优先多媒体设备，失败时尝试控制台设备。
- 设备恢复流程参考 [微软官方说明](https://learn.microsoft.com/en-us/windows/win32/coreaudio/recovering-from-an-invalid-device-error)。

## 验证

- 36 项音乐功能检查通过：持续高能量 300 次新 K 线尝试不再启动第二组；盲盒与开关不能绕过次数；跳转保留次数、切歌恢复机会；合成音频音量、频率及静音响应通过。
- 39 项玩法回归通过。
- 真实酷狗播放 7 秒现场检查：音频包 90 → 619；量能柱最大幅度 0.628 → 0.894 → 0.881 → 0.903；逐次观察的最大变化 0.2730；歌词真实时间 178.12 → 183.60 秒。
- 合成信号检查与真实音乐检查分别记录，不以合成信号冒充现场采集。
- 原目录发布 v0.8.3，发布期间 17 个既有用户数据文件哈希保持一致。日志位于 Docs/Logs/OncePerSongEnergy_*。
